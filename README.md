# ua-quant-bench: результати

Сторінка результатів програмного модуля оцінювання мовної деградації квантизованих мовних моделей для української мови.

Сторінка: https://bogdan264.github.io/ua-quant-bench-results/

Один автономний файл `index.html`, сформований командою `uaqb analyze`. Запити в розділі «Порівняння відповідей» узято з наборів Aya Dataset та OpenAssistant OASST2 (Apache-2.0).
